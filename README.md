# ShiftFit V13 — Installable MVP Foundation

ShiftFit is now structured as an installable web app foundation (PWA).

Included:
- Existing V12 onboarding and connected MVP
- Manifest for installable app behaviour
- Service worker for basic offline caching
- Standalone app display support
- iPhone web-app metadata

Important:
This is an installable PWA foundation, not yet a signed App Store / Google Play native application.

Production build roadmap:
1. Host the app securely over HTTPS.
2. Add real backend accounts and cloud database.
3. Move AI Coach calls to a secure server-side backend.
4. Add real iOS/Android health integrations.
5. Add production push notifications.
6. Package native builds for App Store and Google Play.
